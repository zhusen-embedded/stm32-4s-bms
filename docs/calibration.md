# 标定

## 现在的情况

**还没标定过。** 板子没打出来，下面是打算怎么做，不是做过的结果。

写这个文件是因为标定方案得在打板前想清楚——比如分压电阻的精度、有没有留测试点、校准系数存哪里，这些定了之后改起来麻烦。

## 为什么要标定

分压电阻标称 1%，两个 1% 电阻串起来分压比误差可能到 2%。3.7 V 的单体，2% 就是 74 mV，比保护阈值（过压 4250 mV）的余量还大。

再加上 ADC 本身的偏移和增益误差、运放跟随器的失调，整体偏差可能到几十 mV。所以必须逐通道标定。

## 校准模型

用最简单的线性模型：

```
V_true = V_meas × gain + offset
```

两点就能解出来：

```
gain   = (V_hi_true - V_lo_true) / (V_hi_meas - V_lo_meas)
offset = V_lo_true - V_lo_meas × gain
```

代码里是 `cell_calib_solve()`，传入两个标定点的实测值和真值。

选两个点的话，我打算用 3.20 V 和 4.10 V：

- 3.20 V 接近磷酸铁锂的放电截止区，标定点放这儿能保证低端准
- 4.10 V 接近充满，高端也要准（过压保护靠它）
- 中间段是平台区，两点线性插值在这个区间误差不大

## 标定步骤（计划）

1. 可调直流电源，输出接单体采样输入端（不接真电池，避免电源纹波干扰）
2. 并联一块四位半以上万用表读真值（手上只有三位半的，精度可能不够，得借）
3. 依次设 3.20 V 和 4.10 V，每个点等 30 秒稳定，采 20 次取平均
4. 把四个通道的 gain/offset 算出来，写进 Flash
5. 反过来验证：扫 3.0~4.2 V 每 0.1 V 一点，看校准后的误差

## 校准系数存哪

打算存在 Flash 最后一页（`0x0801FC00`，F103C8T6 是 64 KB Flash）。

结构：

```c
typedef struct {
    uint32_t magic;         // 0x424D5331 ("BMS1")
    cell_calib_t cal[4];    // 四路
    uint16_t crc;           // 防止读出来是乱的
} cal_record_t;
```

上电读出来先校验 magic 和 CRC，不对就用默认值（gain=1, offset=0）并打警告——不能因为校准数据坏了就不工作。

## 精度目标

| 项目 | 目标 | 依据 |
|---|---|---|
| 单体电压 | ±2 mV | 保护阈值判定需要，过压 4250 mV 留 50 mV 余量的话，±2 mV 够用 |
| 总压 | ±20 mV | 四节累加，误差也累加 |
| 电流 | ±10 mA | INA226 分辨率 1 mA，但分流电阻 1% 精度是主要误差源 |
| 温度 | ±1 ℃ | NTC B 值误差 + ADC 量化，实际可能到 ±2 ℃ |

这些是目标，不是实测。

## 已知的误差源

按影响大小排：

1. **分流电阻精度**：0.5 mΩ 的电阻，1% 误差就是 5 µΩ，对应电流误差约 1%。这个没法软件校准，只能买 0.1% 的（贵好几倍）
2. **分压电阻匹配**：两个电阻的相对误差，可以用软件 gain 补偿掉
3. **ADC 参考电压**：F103 用 VDDA 做参考，如果 VDDA 不是精确 3.3 V，所有读数都偏。这个也可以软件补偿，但得先量准 VDDA
4. **运放失调**：跟随器的输入失调电压，用 offset 补偿
5. **ADC 量化**：12 位，3.3 V 满量程，1 LSB 约 0.8 mV，分压后对应单体 3.2 mV。这个是硬下限，所以 ±2 mV 的目标其实卡在量化精度边上

第 5 条要注意：分压比 1:4 的话，ADC 看到的电压是单体的 1/4，1 LSB 对应单体 3.2 mV。想做到 ±2 mV 得靠多次采样平均（噪声随机的话，N 次平均能降 √N）。
