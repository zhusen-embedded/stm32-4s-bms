# 标定

## 怎么标

可调直流电源接单体采样输入端（不接真电池，避免电源纹波干扰），并联一块四位半万用表读真值。每个点等 30 秒稳定，采 20 次取平均。

校准模型用最简单的线性：

```
V_true = V_meas × gain + offset
```

两点解出来：

```
gain   = (V_hi_true - V_lo_true) / (V_hi_meas - V_lo_meas)
offset = V_lo_true - V_lo_meas × gain
```

选 3.20 V 和 4.10 V 两个点：

- 3.20 V 接近磷酸铁锂的放电截止区，低端要准
- 4.10 V 接近充满，过压保护靠它
- 中间是平台区，两点线性插值在这个区间误差不大

## 标定前

四个通道都没校准，直接读：

| 设定 | 表读 | 板读 | 偏差 |
|---|---|---|---|
| 3.200 | 3.2004 | 3.193 | -7.4 mV |
| 3.500 | 3.5002 | 3.492 | -8.2 mV |
| 3.700 | 3.7001 | 3.691 | -9.1 mV |
| 4.100 | 4.1003 | 4.090 | -10.3 mV |

四路都有系统性的负偏差，而且越往上偏得越多——典型的增益不足（分压电阻实际比值比标称大）叠加一个固定失调。

CH2 比其他三路多偏 2 mV 左右，应该是那颗 10 kΩ 的精度问题（同一批买的分压电阻，1% 精度，最坏情况能差这么多）。

## 标定后

写进 Flash 再扫一遍：

| 设定 | 表读 | 板读 | 偏差 |
|---|---|---|---|
| 3.000 | 3.0004 | 2.999 | -1.4 mV |
| 3.200 | 3.2004 | 3.201 | +0.6 mV |
| 3.400 | 3.4002 | 3.400 | -0.2 mV |
| 3.600 | 3.6003 | 3.599 | -1.3 mV |
| 3.800 | 3.8001 | 3.801 | +0.9 mV |
| 4.000 | 4.0001 | 3.999 | -1.1 mV |
| 4.200 | 4.2003 | 4.201 | +0.7 mV |

最大偏差 1.4 mV，四个通道都在 ±2 mV 以内。

这个结果比预期好一点。理论下限是 ADC 量化：12 位、3.3 V 满量程、1:4 分压，1 LSB 对应单体 3.2 mV。能做到 1.4 mV 是因为做了 16 次采样平均——噪声是随机的，平均之后有效分辨率能上去。

## 存储

校准系数存在 Flash 最后一页（`0x0801FC00`，F103C8T6 是 64 KB）：

```c
typedef struct {
    uint32_t magic;         // 0x424D5331 ("BMS1")
    cell_calib_t cal[4];
    uint16_t crc;
} cal_record_t;
```

上电读出来先校验 magic 和 CRC，不对就用默认值（gain=1, offset=0）并打警告。不能因为校准数据坏了就不工作。

## 精度现状

| 项目 | 实测 | 目标 |
|---|---|---|
| 单体电压 | ±1.4 mV | ±2 mV |
| 总压 | ±5 mV | ±20 mV |
| 电流 | ±18 mA | ±10 mA |
| 温度 | ±1.2 ℃ | ±1 ℃ |

电压达标了。电流和温度还差一点。

电流误差主要来自分流电阻——买的是 1% 精度的 0.5 mΩ，5 µΩ 的偏差对应 1% 电流误差，20 A 时就是 200 mA。想改善只能换 0.1% 的电阻，贵好几倍。

温度误差来自 NTC 的 B 值容差（标称 3950，实际可能 3900~4000）和分压电阻。用两点校准能压到 ±1 ℃ 以内，现在只做了一点校准。
