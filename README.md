# 4S BMS 保护板

基于 STM32F103C8T6 的 4 串锂电池管理板，负责单体电压采集、SOC 估算、被动均衡与四级保护，通过 CAN 上报。

## 实测指标

| 项目 | 结果 |
|---|---|
| 单体电压采样抖动 | ±5 mV（中值滤波后） |
| 单体电压精度 | ±2 mV（两点校准后） |
| SOC 误差 | 满充满放 < 3% |
| 保护响应 | 软件 10 ms，短路走硬件比较器 |
| 均衡电流 | 37 mA / 节（100 Ω） |
| 整板物料成本 | 约 40 元 |

## 硬件

- MCU：STM32F103C8T6
- 电流采样：INA226（I2C，0.5 mΩ 分流）
- 隔离 CAN 收发器：TJA1050
- 均衡：100 Ω 泄放电阻 + PMOS 开关

## 踩过的坑

1. 均衡开启时采样串扰 15 mV → 改走线布局 + RC 滤波 + 关均衡 10 ms 后再采，降到 2 mV
2. ADC 尖峰大 → 5 点中值滤波替代均值，均值会把 MOS 开关尖峰摊到整个窗口
3. 上电首帧 CAN 丢失 → 发送前等 TME 位就绪
